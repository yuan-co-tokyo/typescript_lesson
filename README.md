# シンプルToDoリスト

TypeScriptとReactで構築した、最小限の機能を備えたToDoリスト管理アプリです。タスクの追加、一覧表示、完了状態の切り替え、完了済みタスクの一括削除をシンプルなUIで行えます。

## 主な機能
- 入力フォームからタスクを追加
- タスクの完了状態をチェックボックスで切り替え
- 完了済みタスクの一括削除
- 完了数と全体の件数を即時表示

## 必要環境
- Node.js 18 以上
- Yarn もしくは npm

## セットアップ
```bash
yarn install
```

## 開発サーバーの起動
```bash
yarn start
```
ブラウザで `http://localhost:3000` を開くとアプリを確認できます。

## テスト
```bash
yarn test --watchAll=false
```
ユニットテストとコンポーネントテストの両方を実行します。

## プロジェクト構成
```
├── src
│   ├── App.tsx              # アプリ本体
│   ├── App.css              # スタイル定義
│   ├── features/todo        # タスク管理のロジック
│   └── tests/todoUtils.test.ts # タスク操作ロジックの単体テスト
```
